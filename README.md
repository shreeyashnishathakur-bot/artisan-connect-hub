# Artisan Connect Hub

Build a fresh, premium, mobile-first FRONTEND-ONLY prototype for SIH 2026 Problem Statement SIH26090:

“AI-Driven Market Linkage and Smart Cataloging Mobile Application for Marginalized Artisans”

IMPORTANT:

This is ONLY a frontend prototype/demo.

Do NOT build a backend, database, Firebase/Supabase, authentication server, payment system, or real AI/API integrations.

Everything must work through local state, mock data and simulated AI responses.

No API keys should be required.

Every major button and workflow must be clickable and demonstrable.

TECH:

React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Lucide icons + Framer Motion + Recharts.

PRODUCT:

Name: KarigarSetu

Tagline: “Your Craft. Your Story. Your Market.”

The product is a simple “virtual business manager” for marginalized artisans with low digital literacy. The experience must be voice-first, multilingual, minimal and extremely easy to understand.

DESIGN:

Create a beautiful modern Indian craft aesthetic:

warm ivory/cream, terracotta, saffron, indigo, earthy tones, subtle textile/block-print patterns, premium typography, rounded cards and clean spacing.

Do NOT make it look like a generic SaaS dashboard.

Prioritize mobile UX:

- large touch targets

- icons + simple labels

- minimal typing

- voice buttons

- clear progress indicators

- simple navigation

Provide desktop responsiveness too.
